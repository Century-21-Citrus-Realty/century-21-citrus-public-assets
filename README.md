# Century 21 Citrus Realty public website assets



This public, company-owned repository stores only visitor-facing image files used by the Century 21 Citrus Realty website. The private website-code repository remains separate.



The image files are published in GitHub Releases. Do not delete, rename, or replace a release asset unless the website image links are updated and tested at the same time.
